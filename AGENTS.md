# neonburro shop, for any agent

Read `CLAUDE.md` first. It carries the hard rules (JavaScript only, full file rewrites,
yarn never npm, no Oxford commas, no em or en dashes, trailing slashes, path comment on
line one, never handle secrets, never submit a live payment), the theme copy rule, the
map of the shop, the three checkout rails and the env the Netlify site needs.

The wider brand and engineering docs live in the studio repo, `../neonburro/CLAUDE.md`
and `../neonburro/docs/02-engineering/`. Every non trivial file opens with a helper
block explaining why it is shaped the way it is. Read it before the code, leave one
behind in anything you add.
